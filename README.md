# Dash Rev

Customer website for Dash Rev — Car Tech Solutions.

https://dashrev.github.io/

Static HTML, CSS and JavaScript. GitHub Pages publishes the main branch root; no build step. The approved v3 design, customer copy, photographs and pricing are preserved. Brand-specific card links use ?brand=bmw, mercedes, audi, land-rover or volvo. Unknown brands or failed images fall back to BMW.

The guest guide is a vehicle-specific sample, not a finalized handout for every vehicle. Retained Northline PDFs are clearly labeled historical references. No private review portals, local paths or internal skill instructions are published.

Retain bundled font licenses when editing or redistributing assets.
